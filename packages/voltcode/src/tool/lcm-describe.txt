Look up metadata and summary information for an LCM ID (file or summary).

This tool retrieves information about items stored in LCM (Lossless Context Management):

- For file IDs (file_xxx): Returns file path, type, size, token count, and the exploration summary that was generated when the file was first loaded.
- For summary IDs (sum_xxx): Returns summary metadata including level/type, off-context status, lineage pointers, and lineage closure IDs.
- Archive stubs are explicitly labeled in Dolt mode so you can see when a cue points to archived bindle content.
- Use reported lineage pointer targets to traverse hook pointer -> bindle/stub -> expanded source content when available.

Use this tool when you have an LCM ID and need to understand what it refers to before deciding how to work with it.

This tool returns metadata only — NOT the full stored content. To retrieve the actual content, use lcm_read via an explore sub-agent:
  Task(subagent_type="explore", prompt="Use lcm_read on <file_id> to find <what you need>")
